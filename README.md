# Gestión de Productos - Aplicación Full Stack

Aplicación web desarrollada con **Node.js**, **Express.js** y **MongoDB** para la gestión de productos mediante operaciones CRUD, con autenticación y protección de rutas usando **JWT**, pruebas unitarias con **Jest** y despliegue continuo con **GitHub Actions** y **Vercel**.

## Enlace de la aplicación desplegada
- **Producción (Vercel):** https://gestion-productos-fullstack.vercel.app

## Requisitos previos
- Node.js (v18 o superior)
- Cuenta en MongoDB Atlas (o instancia local de MongoDB)

   git clone [https://github.com/KristerTrixter/gestion-productos-fullstack.git](https://github.com/KristerTrixter/gestion-productos-fullstack.git)
